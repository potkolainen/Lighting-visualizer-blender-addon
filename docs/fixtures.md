# Bundled GDTF fixtures

83 fixture files from [GDTF Share](https://gdtf-share.com), stored in `lighting_visualizer/library/gdtf/` (`index.json` lists them). Every file is the work of the uploader named below: **Manufacturer** means uploaded by the manufacturer, **Community** by a GDTF Share user. Community files have not been checked by the manufacturer. Each fixture shows its category and uploader in the Add Lamps list.

Powered by GDTF. DMX modes, optics, physical data and 3D models come from these files; 3D models are real glTF / 3DS meshes where the file has them, otherwise real-size shapes from the GDTF geometry.
